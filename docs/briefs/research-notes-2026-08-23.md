## Pedagogy
- Constructionism: Papert, Mindstorms 1980; LEGO Mindstorms named in his honor; 55-study review of game-making learning; EV3 robotics ed studies show CT gains. https://en.wikipedia.org/wiki/Constructionism_(learning_theory) https://arxiv.org/html/1610.09610v1 https://pmc.ncbi.nlm.nih.gov/articles/PMC4784508/
- AI4K12 (AAAI+CSTA): 5 Big Ideas (Perception; Representation & Reasoning; Learning; Natural Interaction; Societal Impact); grades 6-8 band: societal impact becomes FIRST-CLASS topic. https://ai4k12.org/ https://ai4k12.org/gradeband-progression-charts/
- MIT RAISE DAILy / "How to Train Your Robot": 30-hr curriculum grades 5-8; pilot: significant gains in AI conceptual understanding + bias awareness (n=31, 87% underrepresented in STEM); teachers new to CS could deliver it. https://robots.media.mit.edu/wp-content/uploads/sites/7/2021/03/SIGCSE_2021-DAILy-experience-report.pdf https://ojs.aaai.org/index.php/AAAI/article/view/17847
- Experience AI (Raspberry Pi Foundation + Google DeepMind): FREE curriculum aimed at ages 11-14 (exactly our demo); includes game-based AI Quests w/ Stanford; global teacher training push. https://experience-ai.org/en/ https://www.raspberrypi.org/blog/experience-ai-launch-lessons/
- Teach-back: evidence-based in health literacy (AHRQ endorses; meta-analyses show knowledge + adherence gains, some retention caveats). https://www.ahrq.gov/teamstepps-program/curriculum/communication/tools/teachback.html https://pmc.ncbi.nlm.nih.gov/articles/PMC6590951/
- Protégé effect / teachable agents: expecting-to-teach improves recall + organization (Nestojko et al. via summaries); Stanford AAA Lab (Betty's Brain): students learn more with teachable agents, more effort "for the agent", metacognition gains. https://aaalab.stanford.edu/teachable-agents/research https://aaalab.stanford.edu/papers/Protege_Effect_Teachable_Agents.pdf https://thelearnerlab.com/protege-effect/

## Distribution
- Web-direct: 1.5-1.8MB dist → instant load on school Chromebooks; own domain = own compliance surface + teacher trust (no install); but ZERO built-in discovery.
- CrazyGames: non-exclusive; SDK integration required for monetization; PEGI 12; ≤250MB total / 50MB initial; ad rev-share % undisclosed; monthly payouts ≥€100. https://docs.crazygames.com/
- Poki: prefers Web Exclusive (5yr) — 100% rev when dev brings player, 50% when Poki does; non-exclusive = flat fee; must run 30fps min, mobile+desktop, external requests blocked by default (would conflict with scrap-spark API!). https://docs.crazygames.com/ + Poki dev docs (via search result donislawdev.com summary)
- itch.io: open revenue sharing (dev chooses itch's cut), embeddable iframe widget, no ads on pages, weak kids' discovery but strong indie/press credibility. https://itch.io/docs/creators/faq
- Roblox: NOT a channel for an existing web game — full Luau port required; ~25% effective dev share; 2026 Senate investigation = brand risk for kid-safe positioning. https://rolearn.dev/insights/roblox-developer-revenue-share-2026/ https://www.gamesindustry.biz/us-senate-to-investigate-roblox-following-claims-it-prioritises-revenue-and-engagement-over-child-safety
- COPPA: under-13 personal data = verifiable parental consent; voice recordings ARE personal info; narrow exception only for transient speech-to-text replaced-by-text, promptly deleted; persistent saves + voice features need consent flow or school-contract context. https://www.ftc.gov/news-events/news/press-releases/2017/10/ftc-provides-additional-guidance-coppa-voice-recordings https://www.ftc.gov/business-guidance/resources/childrens-online-privacy-protection-rule-six-step-compliance-plan-your-business
- Note: Poki blocking external requests by default is a REAL technical blocker for scrap-spark-backed Spark + gallery on Poki; CrazyGames SDK allows cloud saves but external calls need review. Web-direct sidesteps all of it.
