Teach Your Robot — Teacher Pack

Scrapcraft Unit 1 · Grades 6–8 · 8 lessons × 45 min · browser-only · no accounts · print freely

Materials (whole unit)

Every lesson: student browser (Chromebook OK) · paper + pencil.
Specific: tape + index cards (L2) · grey paint chips or printed gradient (L3) · printed bug-triage cards (L6) · printer/shared doc (L8).
That's the whole list. No installs, no accounts, no downloads.

Access & Day-Zero (before Lesson 1)

URL: any modern browser; pilots get the URL from the project (public hosting pending) — board before students arrive. Same machine every lesson (saves are local); assign cart seats. Room codes (optional): first names / initials only for display names. Offline plan: every warm-up runs on paper + each lesson has a named paper fallback — no lesson dies with the Wi-Fi. Timing: warm-up (6–7) + frame (3–4) + game (22–25) + teach-back (8–12) + close (2) = 45 exactly; the close is one exit sentence.

Lesson cards

L1A Pile of Parts Is Not a RobotBig Ideas 1·5 (seed)

"I got a crate of motors that never once talked to a sensor. Paperweights."

Learn: power / structure / actuation are three systems; no senses = paperweight.

Do: 7 min Human-Bot pairs → 25 min game Ch1–3, earl-1…earl-5 (first contact is SLOW; the boot beep opens L2 for slow classes) → 8 min Magma teach-back → 2 min close. Tech fails? Paper-design a bot: POWER / STRUCTURE / MOVEMENT boxes + what it still can't do.

Mastery: names all three systems without prompting.

Game: earl-1…earl-5 (earl-6 opens L2)
L2Sense, Think, ActBig Ideas 2·1

"If the bot never checks anything, it just keeps doing the first thing forever?"

Learn: if-tiles inside forever loops; sense→decide→act→repeat.

Do: 6 min Walk-the-Flowchart (taped path; flip one card absurd — the walker never breaks the rule, the rule was wrong) → 25 min Ch4, one knob per run → 8 min teach-back tb-conditionals-1.

Mastery: explains THEN-vs-ELSE; volunteers that both never run in one pass.

Game: earl-6, earl-7
L3Drawing the LineBig Idea 1

"Rivet keeps insisting gray is basically white. You gonna let him get away with that?"

Learn: thresholds are choices, not facts; recalibrate when the world changes.

Do: 6 min "Where does black become white?" (private answers, compare — there is no wrong answer, there is a choice you must justify) → 25 min line-follower + calibration → 8 min Juno teach-back ("why is it drunk in the dusty stacks?").

Mastery: "the sensor's world changed — the old threshold is a lie; recalibrate."

Game: earl-9, bolt-3, ch9-1 (stretch)
L4Same Job, Less CodeBig Idea 2

"You wrote the same three tiles eight times. You building a program or a wall?"

Learn: counted/until loops, variables, subroutines as compression — same lap, fewer tiles.

Do: 7 min shoelace pseudocode + 2-min scoreboard beat ("where does the robot write the lap count?" — a variable is the scoreboard; introduced, not quiz-stressed) → 25 min "Same Lap, Fewer Tiles" (hypothesis sentence required) → 8 min teach-back: forever vs until vs counted.

Mastery: picks loops by "do I know when it ends?" — not by syntax.

Game: bolt-write-shorter, earl-19 (stretch)
L5Which Friend Actually Learns?Big Ideas 3·4 ⚡ AI-literacy center

"Folks ask if I 'know' 'em from last time. Nah — you do the remembering. That's kinda the point."

Learn: Earl & co. are scripts; Spark is a real learned model; "learning from data" in kid words.

Do: 6 min Rule-follower-or-Learner sort (thermostat / autocomplete / adventure book / dog / spam filter — the book is the trick) → 25 min scripted-companion vs Spark (paper fallback if offline) → 8 min "which one LEARNED?"

Mastery: "Earl's writers wrote everything he'll ever say; Spark generates from patterns — new things, and new wrong things."

Offline fallback: paper transcripts — lesson runs with no network
L6The Detective's ClinicBig Ideas 2·1

"The bot sees nothing and decides nothing. Start by asking: what IS the sensor reading right now?"

Learn: hypothesis-first debugging — symptom → hypothesis → ONE change → re-run.

Do: 7 min bug-triage card sort (sensor/logic/power) → 25 min Broken-Bot Clinic ×3 (hypothesis sentence BEFORE touching code) → 8 min Rivet teach-back.

Mastery: reconstructs the evidence chain (symptom → reading → hypothesis → one change), not just the fix.

Game: brokenbot-left-forever / never-stops / wrong-sensor, rivet-2 + bolt-side-3 (stretch)
L7Fail Loudly, Learn PubliclyBig Idea 5 💥 societal impact

"Every wreck wrote a letter. Reading it is the cheapest education you'll ever get."

Learn: failures are data; real robot failures have human costs; write an honest plaque.

Do: 6 min "Who's at fault?" (robot in a pond — pick ONE: sensor/coder/calibration/company, defend) → 25 min plaque wall + write your own plaque → 8 min "why is yours worth one?"

Mastery: the plaque names a cause, not just a crash. (ch8-2's title is narrative; content is offline — no Spark call.)

Game: ch8-1…ch8-3
L8Export Day: The Same Robot, RealBig Ideas 2·5 🎓 capstone

"Chips don't think — they do exactly what you told 'em, in a language you couldn't read last month."

Learn: tiles really compile to C++/MicroPython; every student leaves holding real code with their name in the header.

Do: 6 min Be-the-Compiler → 22 min export chain (print the firmware; flash a board ONLY if IT allows) → 12 min partner-pair expo (60 s each way; teacher circulates with the 3-item checklist: names the idea / shows it in their bot / answers one question; 2–3 volunteers close) → 2 min close.

Capstone debate: "Your threshold works on THIS floor. The school buys darker floors. Who should have thought about that?"

Mastery: finds their name in the firmware header; maps three C++ lines to three tiles.

Game: ch7-1…ch7-3, earl-8/18/20, magma-3…5 · Simulation-first: unit is complete without hardware

Misconception guide

Students say…What's actually trueWhen
"If means maybe"If is a test: TRUE road or ELSE road, never both in one passL2
"Forever loops drain the battery faster"Same speed forever; power is about what's inside the loopL2
"The sensor is wrong"Sensor reports a number; the THRESHOLD decides — and we chose itL3, L6
"One threshold works everywhere"Thresholds are promises to one room (also how bias enters machines — seed it)L3, L8
"Calibration means broken"Calibration is maintenance, not repairL3
"Variables stay locked"Changing is a variable's whole jobL4
"Shorter code is always better"Fewer tiles AND still readable — budgets include humansL4
"Everything that talks is AI"The companions are scripted; Spark is the learned model — knowing which is which IS the lessonL5
"Spark understands me"Spark predicts likely language; it can be wrong in new waysL5
"Debugging means fixing"Debugging means EXPLAINING first — hypothesis, one change, evidenceL6
"It's broken" (reflex)Two of three clinic bugs are logic, not hardwareL6
"Failure is bad"Failure is data; the yard displays it on purposeL7
"The export is magic"It's a translation — find your name, map three lines to three tilesL8
"Simulation is fake"The simulation enforced real constraints all unitL8

Assessment quick-reference

The game tracks unseen → seen → practiced → taught per concept — teaching is the test; rungs only rise; wrong answers route back to practice.

  • SENSE: readings are numbers, thresholds are choices; recalibrates unprompted
  • THINK: predicts before running; picks loops by "do I know when it ends?"; defends compression
  • ACT: names the three systems; describes the loop unprompted; respects budgets
  • ENGINEER: hypothesis chains; honest plaque (cause, not crash); maps tiles → C++ lines

"Not yet" is a location, not a failure.
